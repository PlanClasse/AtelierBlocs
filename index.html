🧩 Atelier blocs

Glissez des blocs ici pour construire un programme.
Clic sur une catégorie (à gauche) : ses blocs s'ouvrent ; glisser un bloc ou cliquer dessus pour l'ajouter · Clic droit sur un bloc : texte de l'algorigramme, dupliquer, noir et blanc, fiche · Bloc relâché sur les catégories : supprimé · Fond : déplacer la vue (molette, Ctrl+molette = zoom)
