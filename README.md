# Atelier blocs mBlock

Construire des programmes avec des blocs du type mBlock 5 (CyberPi + mBot2), puis en faire une fiche d'exercice :
textes, programmes assemblés ou instructions mises à plat (mélangées, valeurs masquées, noir et blanc),
exportée en .docx (A4, marges 1 cm, Aptos 12).

Fichiers : `index.html` (page), `app.js` (moteur, palette, fiche, export), `catalogue.js` (les blocs : catégories,
couleurs, libellés ; syntaxe expliquée en tête du fichier), `docx.iife.js` (bibliothèque docx 9.16, minifiée).

Tout tourne dans le navigateur ; le travail est gardé dans le navigateur (localStorage) et peut être enregistré
dans un fichier .json (bouton Enregistrer / Ouvrir).
